Privacy policy

YouTube-Faceless-Channels · last updated 16 November 2026

What this tool is

YouTube-Faceless-Channels is a private publishing tool. Its owner uses it to upload videos to the owner's own YouTube channels. Nobody else can sign in to it, and it has no website accounts, no sign-up and no tracking.

What it accesses

When the owner signs in with Google, the tool receives permission to act on the owner's YouTube channels through the YouTube API Services. It uses that permission to:

  • upload videos and set their title, description, tags, thumbnail, privacy status and publish time;
  • create playlists on the channel and add the uploaded videos to them;
  • read the channel's own video and analytics figures (views, watch time) to plan later videos.

It does not read data of viewers, commenters or any other YouTube user beyond what YouTube shows the channel owner in aggregate.

What it stores

The sign-in token and the figures it reads are stored only on the owner's computer. They are not sent to any other party, not sold and not used for advertising. Figures read from YouTube are refreshed or deleted within 30 days.

How to withdraw access

Access can be withdrawn at any time on Google's security settings page, myaccount.google.com/permissions. Deleting the token file on the owner's computer has the same effect for this tool.

YouTube and Google

The tool uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
